# Лентикулярная коррекция смешанного астигматизма — презентация

- `index.html` — веб-версия (24 слайда). Листать: стрелки, пробел, свайп; `F` — полный экран.
- `Лентикулярная_коррекция_смешанного_астигматизма.pptx` — редактируемая версия для PowerPoint/Keynote:
  текст, карточки и графики — родные объекты (графики правятся через «Изменить данные»).
  Шрифт — **Manrope** (бесплатный, Google Fonts). Установите его, чтобы слайды выглядели как задумано.

## Как пересобрать после правок

Текст и цифры всех слайдов лежат в `build/slides.py`.

```bash
python3 build/slides.py        # -> build/deck.json
python3 build/build_html.py    # -> index.html
node build/build_pptx.js       # -> .pptx (нужен пакет pptxgenjs@3.12.0)
```
