# Современный подход к хирургической коррекции смешанного астигматизма — презентация

Исходная презентация (20 слайдов, текст и графики автора) в новом оформлении: цвета — по референсу 1, расположение блоков — по референсу 2.

- `index.html` — веб-версия (20 слайдов). Листать: стрелки, пробел, свайп; `F` — полный экран.
- `Коррекция_смешанного_астигматизма_новый_дизайн.pptx` — редактируемая версия для PowerPoint/Keynote:
  текст, таблицы и карточки — родные объекты; графики результатов вставлены картинками из исходной презентации.
  Шрифт — **Manrope** (бесплатный, Google Fonts). Установите его, чтобы слайды выглядели как задумано.

## Как пересобрать после правок

Текст и цифры всех слайдов лежат в `build/slides.py`.

```bash
python3 build/slides.py        # -> build/deck.json
python3 build/build_html.py    # -> index.html
node build/build_pptx.js       # -> .pptx (нужен пакет pptxgenjs@3.12.0)
```
