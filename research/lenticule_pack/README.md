# Лентикула SMILE: 3D-модель, рендер в Blender, конечно-элементный расчёт

Один набор формул (торическое приближение Мунерлина) используется везде: геометрия → 3D-сетка → рендер → КЭ-расчёт → файлы для ANSYS/CalculiX.
Толщина лентикулы в точке (x, y), мкм: `t = t0 + [Sph·(x²+y²) + Cyl·(−x·sinα + y·cosα)²] / (2(n−1))`, n = 1,376; t0 подбирается так, чтобы на самом тонком краю было tmin.

## Конечно-элементный расчёт: что он говорит и чего НЕ говорит

Что считается: роговица (купол R = 7,8 мм, толщина от 0,54 мм в центре), «до» и «после» (передняя поверхность опущена на толщину лентикулы), давление 15 мм рт. ст. изнутри, лимб закреплён. Выдаёт: смещение вершины, карту разницы смещений, ΔK по двум меридианам (только геометрия и геометрия + нагрузка), напряжения.

Чувствительность к жёсткости (линейный модуль E; лентикула Sph +1,0 / Cyl −4,0, ось 0°):

| E, МПа | вершина до, мкм | ΔK крутой меридиан: только геометрия | ΔK крутой меридиан: с давлением | ΔK плоский меридиан: с давлением (только геометрия +0,90) |
|---|---|---|---|---|
| 0,3 | 326 | −2,69 | −0,29 | −0,48 |
| 1,0 | 98 | −2,69 | −1,97 | +0,48 |
| 3,0 | 33 | −2,69 | −2,45 | +0,76 |

Как читать: результат «с давлением» зависит от E в несколько раз, значит абсолютные числа этой модели ненадёжны. Причины: линейная упругость, геометрия «до» принята ненапряжённой (на деле измеренная форма уже под давлением), нет анизотропии коллагена, эпителия и регресса. Поэтому:
* модель НЕ объясняет и НЕ подтверждает наблюдаемое в ваших данных «0,72 дптр на диоптрию меридиана»; случайное совпадение при каком-то E ничего не значило бы (это подгонка одного параметра под одно число);
* надёжны только проверки кода (геометрия и решатель), они есть в `fem_validation.py`;
* чтобы модель стала инструментом, нужны нелинейная гиперупругость, предварительное напряжение (опорная форма = измеренная) и жёсткость, откалиброванная по Corvis (SP-A1) — это задача для Claude Code ниже.

## Запуск в ANSYS (и в CalculiX)

1. `python3 fe_export.py --sph ... --cyl ... --axis ... --E 1.0 --nu 0.45 --iop 15 --out fe_decks`
2. ANSYS Mechanical APDL: File → Read Input from… → `ansys_pre.inp`, затем `ansys_post.inp`. Файл задаёт SOLID185 (смешанная формулировка), материал, узлы, элементы, закрепление лимба, давление на заднюю поверхность, большие перемещения; в конце записывает смещения узлов в `disp_pre.txt` / `disp_post.txt`. 3. Для сверки: вершина должна сместиться примерно на 100–120 мкм (E = 1 МПа); отличие от scikit-fem на ~10 % нормально.
4. CalculiX: `ccx calculix_pre` и `ccx calculix_post`; смещение вершины печатается в `*.dat`.

## Задача 1 — нелинейная модель с предварительным напряжением (`fem_hyper.py`)

**Постановка.** Полная лагранжева постановка, метод Ньютона с согласованной касательной матрицей; элементы — 27-узловые квадратичные гексаэдры (та же сетка, что в `fem_lenticule.py`); ВГД — следящее давление на заднюю поверхность (с касательной «нагрузочной» матрицей), лимб закреплён.
Материал (в форме Abaqus/CalculiX, чтобы можно было сверяться):
* нео-Гук: `W = C10·(J^(−2/3)·I1 − 3) + (J − 1)²/D1`, `C10 = μ/2`, `D1 = 2/K` (при малых деформациях — то же E, ν, что в линейной модели);
* HGO: + две семьи волокон в плоскости роговицы (проекции осей x и y на касательную к куполу), `W_f = k1/(2k2)·(exp(k2(I4 − 1)²) − 1)`, только при растяжении волокна.

Напряжение `P = ∂W/∂F` и касательная `∂P/∂F` выписаны явно; обе проверяются конечными разностями (тест 1).

**Предварительное напряжение.** Измеренная форма считается формой ПОД ВГД. Ненапряжённая форма ищется итерационно (Sellier 2011): `X ← X − (x(X) − x_измер)`. Сходится за 5 итераций до 0,02 мкм. Операция «после» выполняется в ненапряжённой конфигурации: передняя поверхность опускается на толщину лентикулы, пересчитанную на ненапряжённое состояние. Затем снова прикладывается ВГД.

**Как считается ΔK.** По полному КЭ-полю, то есть по всем узлам Hex27 передней поверхности, а не только по вершинам:
* смещение поверхности = (опускание по формуле толщины) + `u_z(после) − u_z(до)`;
* по точкам r < 2,5 мм строится квадратичная поверхность, по ней берётся кривизна вдоль оси и поперёк неё.

Без нагрузки метрика даёт ровно оптику 0,8975·P на всех сетках (тест 6а). Прежняя оценка по вершинам на одной линии сохранена как `dK_*_nodes`: на грубых сетках она шумит, потому что в зону r < 2 мм попадают всего 3–9 узлов.

## Задача 2 — калибровка по Corvis ST и чувствительность (`calibrate_corvis.py`)

**Что такое суррогат.** SP-A1 — динамический показатель: (давление струи в момент 1-й аппланации − bIOP) / смещение вершины. Модель квазистатическая. Поэтому считается **суррогат** `S = Δp / Δz_вершины`: к нагруженной ВГД роговице прикладывается «струя» `p(r) = 10 мм рт. ст. · exp(−r²/2σ²)`, σ = 1,5 мм (допущение). Связь принята как `S = κ·SP-A1`, κ = 1. **Это не откалиброванная связь.** Подобранный E — «эффективный модуль модели», а не измеренная жёсткость ткани.

**Как идёт подбор.**
* подбор E методом секущих по log E на сетке 8×8×2, 2–3 расчёта на глаз;
* итоговый расчёт «до/после» — на сетке 12×12×3; S там отличается от цели на ~2 %, это эффект сетки.

**Свои данные.** CSV с колонками `code;cct_um;iop_mmHg;r_ant_mm;sp_a1;sph;cyl;axis;oz;tmin`, только коды глаз, без ФИО. Запуск: `python3 calibrate_corvis.py --eyes мои_глаза.csv --out out/corvis_my`.

* ВГД — второй по силе фактор (−2,23 при 10 и −1,86 при 20 мм рт. ст.). CCT, радиус кривизны и ширина переходной зоны дают ≤ 0,1 дптр — это сравнимо с погрешностью сетки;
* суррогат жёсткости S после удаления лентикулы падает на 10–14 %, напряжение в оптической зоне растёт на 13–23 %. Знак ожидаемый: тоньше — мягче и напряжённее; величины зависят от допущений (форма струи, κ = 1, квазистатика);
* отношение ΔK крутого меридиана к его силе у ДЕМО-глаз ≈ 0,53. Это НЕ сравнение с вашим наблюдением 0,72 — глаза выдуманные, а суррогат SP-A1 не откалиброван;
* у DEMO-02 плоский меридиан почти не корригируется (+0,25 D), поэтому отношение ΔK/сила на рисунке велико и неинформативно (деление на малую величину).

## Задача 3 — визуализация (`blender_lenticule.py`)

* `--labels` — подписи толщины на краю шрифтом с кириллицей. Шрифт ищется автоматически: DejaVu Sans или Noto Sans в Linux, Arial в macOS и Windows; свой задаётся через `--font путь.ttf`, единицы — через `--unit` (по умолчанию «мкм»).
* Подпись видна только на ближней к зрителю стороне. Каждый кадр она ставится у своей точки края, сдвигается наружу и вниз, чтобы не ложиться на лентикулу. Дальние подписи и подписи при сильном наклоне скрываются.
* Вариант без цифр — запуск без `--labels`.
* `--video` после кадров собирает MP4 (H.264, 24 кадра/с) и GIF (палитра, ширина до 600 px).
* `--frame-range 111-220` — перерендерить только часть кадров.
* Проверено запуском: Blender 5.2.3 LTS (Python 3.13) и 4.5.15 LTS (Python 3.11), Cycles и Eevee. Eevee — через программный OpenGL Mesa (`apt install libegl1 libgl1-mesa-dri`), на видеокарте не проверялся.

Пример: `python3 blender_lenticule.py --labels --video --res 720 --samples 48 --out out/blender/lentikula_podpisi`

## 3D-схема операции SMILE (`blender_smile_procedure.py`)

Один ролик без текста, ≈60 с при 24 к/с (1450 кадров), светлая студия (как в присланных примерах):

| Этап | Что показано |
|---|---|
| Глаз | целый глаз: склера с сосудами, прозрачная роговица (стекло, n = 1,376), цветная радужка с радиальными волокнами и коллереткой, прозрачный хрусталик |
| Фиксация | интерфейс в стиле VisuMax (изогнутая контактная линза, прозрачный конус, кольцо с рёбрами) опускается на роговицу |
| Лазер, вид сбоку | роговица **целая**. Пузырьки ставятся **по одному** (сначала замедленно, затем ускоренно): дно лентикулы — спираль от периферии к центру → боковой рез → верх (граница колпачка, 120 мкм) — спираль от центра к периферии |
| Лентикула | **только после дна и верха** проявляется лентикула: цвет по меридианам — плоский зелёный, крутой красный, плюс линии меридианов |
| Разрез доступа | 2,5 мм на 120°, крупно сверху |
| Профиль | после всех резов роговица раскрывается по плоскому и крутому меридианам; профили крупно сбоку (седловидная форма) |
| Извлечение | шпатель (передняя, затем задняя поверхность); пинцет; лентикула **гладкая**, мягко сворачивается в «трубочку» и выходит через разрез |
| Финал | пинцет уходит из кадра; лентикула упруго расправляется; вырез по меридианам и **крупно каждый профиль** (толщина плавно ×3 → ×8) |

Запуск: `python3 blender_smile_procedure.py --out out/smile --width 960 --height 540 --samples 8 --video` → `<out>.mp4`, `<out>.gif`.
Параметры лентикулы — `--sph --cyl --axis --oz --tmin`; колпачок `--cap 120 --cap-d 7.5`; разрез `--inc-angle 120 --inc-width 2.5`.
С заголовками этапов — `--text` (заголовки не обновлялись под этот сюжет).

Это **схема, не расчёт**: толщина лентикулы ×3 (на финальных крупных планах ×8), пузырьки и шаг спирали увеличены (реально — единицы
микрометров и сотни тысяч импульсов), ИК-излучение показано условным голубым цветом, сворачивание лентикулы при извлечении — наглядное,
не механическое. Размеры глаза — типичные. На крупных планах лазера интерфейс плавно скрывается, чтобы не закрывать роговицу.
Проверено запуском: Blender 5.2.3, Cycles на процессоре (≈3–22 с на кадр при 960×540; весь ролик ≈5–6 ч).

## Честные ограничения модели лентикулы
* Параболическое приближение, без переходной зоны (в КЭ-модели край сглажен косинусом шириной 0,5 мм — это допущение).
* Основа — Munnerlyn C.R., Koons S.J., Marshall J. J Cataract Refract Surg 1988;14(1):46–52 (PRK). Торическое обобщение и перенос на лентикулу SMILE — стандартное приближение, но в самой статье его нет.
* По Пентакаму модель подтверждена по центру (5 глаз из 6 в пределах ±10 мкм) и по крутому меридиану (ΔK около 0,72 от силы, ожидание по оптике 0,90); край вдоль оси цилиндра по этим данным не проверен (нужна числовая матрица толщины).
